# Мої 3 найкращі міста світу — ЛР1

Статичний багатосторінковий сайт (HTML) з дисципліни «WEB-програмування».

- `index.html` — головна сторінка з рейтингом;
- `city-madrid.html`, `city-monaco.html`, `city-los-angeles.html` — сторінки міст;
- `form.html` — форма «Запропонувати місто»;
- `images/` — фото з Wikimedia Commons (автори й ліцензії — під фото та в `credits.json`);
- `css/style.css` — мінімальні стилі для читабельності.
